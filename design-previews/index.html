个人站风格对比

同一内容骨架（Hero / 关于 / 项目卡 / 博客入口），套用 awesome-design-md 中 5 套 DESIGN 语言。正式站点当前采用 Linear 深色裁剪版（展示名 陈懂）。

打开各预览可单独全屏查看。源码来自 design-previews/*.html，仅作选型，不参与构建产物。

1. Linear（当前正式站）

深色 紫强调 极简 SaaS Active
单独打开 →

近黑画布 + 薰衣草强调色。工程感强，适合协议/基础设施类个人品牌。

2. Vercel

浅色 黑白精密 开发者
单独打开 →

近白画布 + 墨色 CTA + 细边框卡片。备选浅色方案。

3. Mintlify

浅色 绿色强调 文档感
单独打开 →

文档站气质，黑 pill + mint 强调。读感好，个人品牌辨识度略弱于 Vercel/Claude。

4. Resend

深色 衬线标题 杂志感
单独打开 →

纯黑底 + 衬线大标题。有编辑质感，但对中文个人站略「重」，技术笔记场景可玩性一般。

5. Claude

暖色 奶油底 人文编辑
单独打开 →

奶油画布 + 珊瑚 CTA + 衬线标题。温暖、适合写作向个人站；与「车联网/协议工程」硬核气质略有温差。

正式站默认风格见仓库根目录 DESIGN.md（Linear 裁剪）。换肤：改 CSS 变量映射，勿散改组件结构。
